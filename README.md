## Identidade visual

A página é desenhada como uma sessão de terminal/IDE: fundo escuro com viés azul-petróleo, um único
acento coral (`#ff7a59`), e **JetBrains Mono** — a fonte que devs realmente usam pra codar — nas tags
de stack, labels e no terminal do hero. Verde e âmbar aparecem só como status semântico (online/protótipo),
nunca como acento principal.

Tipografia: **Bricolage Grotesque** nos títulos, **Manrope** no corpo do texto.

## Estrutura

- `index.html` — conteúdo (hero, projetos, sobre, contato)
- `style.css` — todo o visual
- `script.js` — efeito de digitação no terminal do hero + parallax dos chips de status
