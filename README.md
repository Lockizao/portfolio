# Portfólio — Matheus Felipe

Meu portfólio pessoal. HTML, CSS e JS puro, sem build e sem framework, publicado direto via GitHub Pages.

Ver ao vivo: https://lockizao.github.io/portfolio/

## Sobre a identidade visual

Desenhei a página inteira em torno da ideia de uma sessão de terminal: fundo escuro com um leve azul-petróleo, um acento coral único e JetBrains Mono (a fonte que uso de verdade pra codar) nas tags de tecnologia, nos labels e no terminal animado do topo. Verde e âmbar só aparecem como indicador de status (online/protótipo), nunca como cor principal — quis evitar acento demais competindo entre si.

Pra título uso Bricolage Grotesque, e o corpo do texto é em Manrope.

## Estrutura

- `index.html` — todo o conteúdo (hero, projetos, sobre, contato)
- `style.css` — o visual
- `script.js` — o efeito de digitação do terminal e o parallax dos cartões de status atrás do hero
